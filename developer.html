Archivo Tenno / Desarrolladores

Detrás de cada aventura, un equipo.

Archivo Tenno es un proyecto de fans que nace de la pasión por crear contenido útil, seguro y accesible para la comunidad de Warframe.

Desarrollar una página de información no requiere nombres inventados ni perfiles falsos. Esta sección explica cómo trabaja el equipo detrás de este proyecto y qué responsabilidades sostienen las distintas partes de la experiencia.

01 / Equipo

El equipo detrás de la experiencia

El proyecto se construye mediante la colaboración de personas que comparten conocimientos de diseño, desarrollo, contenido y accesibilidad. Cada integrante aporta una perspectiva diferente y ayuda a mantener la información clara, útil y fácil de explorar.

Los perfiles de esta sección están diseñados para poder completarlos con nombres, funciones y enlaces reales cuando el equipo lo desee. Mientras tanto, sirven como una guía sobre cómo se organiza la responsabilidad del proyecto.

Rol de equipo

Desarrollo web

Construye la estructura, la interacción y el comportamiento de las páginas para que funcionen en distintos dispositivos.

Rol de equipo

Diseño de contenido

Organiza la información y transforma los datos complejos en secciones claras, interesantes y fáciles de consultar.

Rol de equipo

Accesibilidad

Comprueba navegación, contraste, estructuras semánticas y experiencias que funcionen con lectores de pantalla y teclado.

02 / Responsabilidades

Contribuciones que mantienen el proyecto vivo

El desarrollo de un sitio web no depende únicamente de escribir código. También requiere mantener las páginas actuales, revisar los enlaces, comprobar que los contenidos siguen siendo relevantes y mejorar la experiencia de quienes utilizan el proyecto.

La cooperación entre roles permite que cada cambio tenga una visión completa: una estructura correcta, una presentación atractiva, texto útil y una experiencia accesible.

03 / Herramientas

El entorno de trabajo

El proyecto utiliza tecnologías web sencillas y modernas para mantener el código fácil de revisar y actualizar. La combinación de HTML, CSS y JavaScript permite crear páginas muy funcionales sin depender de una plataforma compleja.

HTML

Define la estructura de cada página y los elementos que se pueden consultar.

CSS

Controla el diseño, los colores, los espacios y la adaptación a distintas pantallas.

JavaScript

Añade comportamiento ligero para mejorar la navegación y los enlaces de la interfaz.

Herramientas de edición

Permiten revisar el código, detectar errores y preparar los cambios antes de publicarlos.

04 / Filosofía

Crear para compartir, no para competir

Este proyecto busca ofrecer una experiencia orientada a la colaboración y al aprendizaje. No pretende sustituir el contenido oficial ni representar a Digital Extremes. La intención es proporcionar un espacio personal para descubrir el universo, consultar información y compartir experiencias.

Nota importante:

Archivo Tenno es un proyecto de fans y no está afiliado ni autorizado por Digital Extremes. Los datos y las imágenes podrán necesitar actualizarse cuando cambie la información oficial del juego.
